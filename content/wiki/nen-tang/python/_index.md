Python giúp mình đọc file, kiểm tra dữ liệu và nối các bước thành một pipeline. Bắt đầu nhỏ: hiểu code đang xử lý từng dòng thế nào, rồi mới thêm database hoặc framework.

- [Script Python đầu tiên]({{< relref "/wiki/nen-tang/python/overview.md" >}}): biến, vòng lặp, hàm và cách chạy.
- [Đọc CSV và JSON]({{< relref "/wiki/nen-tang/python/files-and-json.md" >}}): dữ liệu chữ, kiểu dữ liệu và mã hóa.
- [Lỗi và logging]({{< relref "/wiki/nen-tang/python/errors-and-logging.md" >}}): phân biệt dữ liệu sai với lỗi chương trình.

Các bài về module, môi trường, database và HTTP client đang được bổ sung. Ba ví dụ hiện tại dùng thư viện chuẩn và đã chạy trên Python 3.12; chưa phải một pipeline vận hành đầy đủ.
